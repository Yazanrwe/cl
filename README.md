# Clickable Links (Fabric 1.20.1)

Client-side mod that makes every link in chat (`http://`, `https://`, `www.`) clickable.
Click opens the usual Minecraft "Open link?" confirmation. Hovering shows the full URL.

Requires: Minecraft 1.20.1, Fabric Loader >= 0.14.21 (Fabric API is not needed).

## Getting the .jar from GitHub
1. Create a new GitHub repository and upload all files from this folder (keep the `.github` folder).
2. Open the **Actions** tab. The "Build mod" workflow starts automatically on push.
3. When it finishes, open the run and download the artifact **clickable-links** (a zip containing the .jar).
4. Put the .jar in `.minecraft/mods`.
